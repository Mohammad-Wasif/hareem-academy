# Project Memory — Dependencies Catalog

Core third-party modules across workspaces.

- **`cors`**: Origin validations
- **`pino`**: Structural logging engine

## 3. Frontend Package Dependencies
- **`react`** & **`react-dom`**: Version `18`
- **`wouter`**: SPA routing
- **`@tanstack/react-query`**: Server state query caches
- **`framer-motion`**: CSS visual animation transitions
- **`tailwind-merge`** & **`clsx`**: Formatting UI utility class combinations
