# Project Memory — Overview Summary

High-level summary of the Hareem Academy digital platform.

---

## 1. Academy Domain Vision
Hareem Academy provides structured online Arabic, Tajweed, and Urdu classes designed exclusively for women (sisters-only batches). Modesty, privacy, and qualified female native teachers are non-negotiable constraints of the institution.

## 2. Core Capabilities
- **Enrollment CRM**: Captures public student leads and converts them to paid batch seats with direct WhatsApp communication integrations.
- **Dynamic visual Page Builder**: Administrative interface to visually re-arrange, style, and edit landing page copywriting blocks and terms/policy texts on live URLs.
- **Cloudinary Asset edge hosting**: Optimizes image uploads (converting PNGs/JPEGs to WEBP) and manages alt metadata.
- **Site configurations editor**: Changes visual themes, SMTP settings, Google analytics tags, and floating WhatsApp parameters in the database.
